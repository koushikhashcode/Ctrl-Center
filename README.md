# Digital Control Center

A modern, highly customizable personal launcher and digital command center built with React, Tailwind CSS, and Vite. 

Designed as a bento-grid editorial workspace, the Digital Control Center gives you quick access to your most important links, tools, daily scratchpad notes, private vaults, and a built-in audio player.

## Features

- **Personal Workspace & Scratchpad:** A quick-access notepad that auto-resizes to your content.
- **Audio Vault:** Listen to your local tracks seamlessly while working.
- **Bento Grid Design:** A beautiful, responsive editorial layout.
- **Private Document Vault:** A dedicated section to organize your PDFs and important files.
- **Search & Quick Actions:** Quickly search your tools, links, and documents.

## Running Locally

**Prerequisites:** [Node.js](https://nodejs.org/) (v16 or higher)

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

## Configuration

All configuration, links, tools, and vault files are managed through code.
Update your data directly in `src/data/defaultData.jsx` to customize your workspace.
